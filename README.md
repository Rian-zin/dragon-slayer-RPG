Dragon Slayer v1.0 ⚔️
Um jogo de batalha por turnos desenvolvido em Python para praticar lógica de programação.

🔨 Funcionalidades
Sistema de Combate: Turnos alternados entre Jogador e CPU.
Mecânica de Risco: Ataques com chance de erro (Crítico/Falha).
Cura Inteligente: Sistema de poção que respeita o limite máximo de HP.
Feedback Visual: Uso de time para criar suspense e narrativa na batalha.
Código Modular: Uso de funções (def) para evitar repetição de código.
🚀 Como jogar
Certifique-se de ter o Python instalado.
Clone o repositório.
Execute o arquivo: dragon-slayer.py
